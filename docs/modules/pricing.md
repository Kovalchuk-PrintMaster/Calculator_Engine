# Движок ціноутворення

## Конвеєр
1) Pick tier по `(variant_id, qty)`
2) Модифікатор аудиторії (b2c/b2b/partner)
3) Опції (fixed/percent/per_unit)
4) ПДВ та округлення
5) Повертаємо стабільний `breakdown`

## Поточний MVP
- Валідація `qty >= 1`.
- Аудиторії: `b2c`, `b2b`, `partner` (інші → 400 у роутері).
- Повертаємо детерміновані значення-заглушки, щоб фронт рухався.

## Тести
- Unit для «чистої» математики.
- Golden-тести для критичних кейсів.
