# ADR-0001 — Структура репозиторію та правила

**Статус**: прийнято — 2025-10-11

## Контекст
Потрібна підтримувана структура з чіткими зонами відповідальності, чистим коренем і передбачуваними імпортами.

## Рішення
- **src-layout**: код під `src/`, пакет `calculator_engine`.
- Розподіл:
  - `app/` — API, роутери, middleware (без бізнес-логіки).
  - `domain/` — чиста бізнес-логіка (без IO).
  - `infra/` — адаптери (БД, кеш, S3, email, pdf).
  - `config/` — шляхи та налаштування.
  - `shared/` — утиліти, константи (без секретів), типи.
- Конфіги: `defaults < base.toml < {ENV}.toml < env`.
- Документація й коментарі — **українською**.

## Наслідки
- Легке онбординг та рефакторинг.
- Якісні «шви» для тестування (unit, integration).
- Локально потрібен `PYTHONPATH=src` (вже налаштовано).
