Що вже є (короткий аналіз)

Каркас FastAPI + Uvicorn: /health, /meta (ping/info), /price/quote (каркас) — все проходить тести.

Роутери та шарова структура: app/main.py мінімальний, бізнес-ендпоїнти винесені в routers/*.

Request-ID middleware + контекст: генеруємо/прокидуємо X-Request-ID, є ContextVar і фільтр для логів.

Логування: є setup_logging() з консольним human-readable форматором і CSV-логом; тести на логування «зелені».

Документація (укр.): каркас docs/ + рішення щодо структури (логіка, модулі, константи, БД тощо).

CI (GitHub Actions): лінтери (ruff/black), mypy, pytest; локально — Makefile/pytest профілі.

Пакетування: pyproject.toml + pip install -e .; імпорт пакета працює.

Шляхи/логи: централізовані константи в config/paths.py, створення службових тек, у т.ч. logs/autentification, logs/data_base.
