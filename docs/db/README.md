# Документація по базі даних

## Призначення
Описуємо логічну модель БД, таблиці, звʼязки, індекси, політики міграцій.

## Актуальний DSN
- Береться з `config/*.toml` або з env (`POSTGRES_DSN`), дефолт — з `settings/app_settings.py`.

## Міграції
- План: підключити **Alembic** (окремим кроком).
- Вести версії у `db/migrations/` і документувати зміни у `docs/db/migrations.md`.

## Схема
- Візуальні діаграми у `docs/db/schema/` (PlantUML / Mermaid / PNG).
- Текстовий опис таблиць — див. `docs/db/schema/tables.md`.

## Перевірка доступності БД
- Локально: `make db-ping` (виконує `SELECT 1`).
