# Індекси та продуктивність

## Загальні правила
- Індекс лише там, де справді є фільтри/джойни.
- Combo-індекси для частих поєднань умов.
- Partial indexes (наприклад, `WHERE is_active = true`).

## JSONB
- GIN на шляхах, які фільтруються (`attributes->>'color'` тощо).
- За потреби — generated columns + btree індекс на них.

## Аналіз
- Регулярно проганяти `EXPLAIN ANALYZE` для гарячих запитів.
- Виявляти низький cache hit на Redis → підбирати TTL/інвалідацію.

## В’юхи
- Матеріалізовані — для важких агрегатів («from-price»), рефреш після політик.
