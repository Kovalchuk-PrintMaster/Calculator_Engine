# Таблиці (чернетка)

> Надалі наповнимо під час реалізації моделі ціноутворення.

- `products` — каталог продукції (формат, матеріали, базові ціни).
- `quotes`   — калькуляції/кошториси (вхідні параметри, обрахована ціна).
- `orders`   — замовлення клієнтів (звʼязок із `quotes`, стан замовлення).
- `materials`/`pricing_rules` — довідники та правила ціноутворення.

Для кожної таблиці опишемо:
- призначення;
- ключові поля, типи, індекси, обмеження;
- зовнішні ключі та каскади;
- приклади запитів.
