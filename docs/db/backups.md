# Бекапи та відновлення

## Політика бекапів
- Щоденний `pg_dump` у S3-бакет (`s3_bucket_backups`), з увімкненим versioning.
- Ротація: 7 щоденних, 4 тижневих, 6 місячних (приклад).

## WAL-архівація (пізніше)
- Для мінімізації втрат даних — підключити `wal-g`/`wal-e`.

## Тести відновлення
- Раз на N тижнів — відновлення на stage/okруження.
- Чек-лист: консистентність, валідність даних, працездатність API.
